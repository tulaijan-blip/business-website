# Бизнес × ИИ

Адаптивный сайт-визитка на русском языке для предпринимателя в области ИИ и автоматизации. Чистые HTML, CSS и JavaScript, без сторонних библиотек, шрифтов, аналитики и сборки.

## Посмотреть

Откройте `index.html` в браузере — установка не нужна.

Или используйте Node.js 18+:

```sh
cd business-website
npm start
```

Откройте http://localhost:3000. Из корня уже открытого репозитория достаточно `npm start`. Для другого порта: `PORT=8080 npm start`.

## Заполнить данные

В `assets/config.js` укажите имя и настоящий Telegram username без `@`:

```js
window.SITE_CONFIG = {
  name: 'Ваше имя',
  telegramUsername: 'your_username',
};
```

До заполнения Telegram кнопка открывает честное уведомление о том, что контакт ещё не указан. После заполнения открывается личный диалог через `https://t.me/…`. Имя по умолчанию обозначено как `[Ваше имя]`. Не храните здесь токены ботов или другие секреты: файл публичный.

Тексты и разделы редактируются в `index.html`, оформление — в `assets/style.css`. Светлое оформление использует молочный фон, глубокий синий и золотые акценты. Справа на первом экране размещён портрет Тулеуовой Айтжан в естественных пропорциях, без обрезки. Достижения, отзывы и результаты клиентов не добавлены.

## Проверка

```sh
npm run check
```

## Размещение

Загрузите `index.html` и папку `assets` на любой статический хостинг, например GitHub Pages. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → нужную ветку → `/ (root)`. Внешние сервисы и серверная база данных не требуются.

## Скачать и открыть на компьютере

Готовый автономный файл: `ready-to-share/website.html`. Откройте его двойным щелчком. Интернет и установка не нужны. Архив `ready-to-share/website-ready.zip` содержит этот же файл.

После любых изменений пересоберите оба файла из корня репозитория:

```sh
python3 scripts/package-website.py
```

Имя и Telegram редактируются в `assets/config.js`. После изменений повторите сборку. Портрет хранится в `assets/Элегантный деловой портрет в офисе.png`. Сборщик встраивает снимок внутрь автономной страницы, поэтому фотография отображается без интернета. CSS сохраняет естественные пропорции.
